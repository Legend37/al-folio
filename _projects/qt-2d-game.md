Qt 2D Fighting Game is a small 2D fighting game developed in C++ with Qt 6 as a programming course assignment in the summer semester of 2025.

The game includes characters, weapons, equipment, and consumable items. The repository provides the source code and CMake build instructions for Windows and macOS.
